Non-Orthogonal Multiple Access (NOMA) Enabled LPWA Networks

This project aims to efficiently design algorithms that optimize the resource allocation (RA) for lpwan with a special focus on lora. The RA algorithms are optimized in a way to either maximize the user fairness through maximizing the minimum rate of all rates or to maximize the sum rate. They can also be optimized in a way to maximize the energy efficiency of lpwans. Multiple access techniques such as time division miltiple access (TDMA) or nonorthogonal multiple access (NOMA) can be concurrently used. RA algorithms can be designed to allocate channels, user grouping, time duration, spreading factors, transmit powers and techniques from convex optimization, matching theory can be used.
